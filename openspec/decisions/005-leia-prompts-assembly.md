# ADR-005: Промпты Леи — основной + блок

## Decision

Все AI-вызовы Леи собирают system prompt как:

```
ОСНОВНОЙ ПРОМТ (без переменных) + "\n\n" + БЛОК (с подстановкой)
```

Основной промпт всегда первый — для кэширования у провайдера.
Числа/арканы считает бэкенд (`NumerologyService.prompt_vars`), модель только интерпретирует.

## Consequences

- Старые `numerology_ru.md` / `tarot_ru.md` / `astro_ru.md` больше не склеиваются в product/chat system.
- Утренняя «карта дня» заменена двухслойным прогнозом по знаку + personal day.
- Антиповтор рассылок через `{last_7}` из `notifications.payload`.
