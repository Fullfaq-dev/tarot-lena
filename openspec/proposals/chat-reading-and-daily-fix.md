# Разбор переписки + фикс ежедневной рассылки

## Summary

1. Ежедневка по `leya-daily-fix`: `{sign_theme}`, таблица чисел, `{link_type}` с бэкенда, `{last_7}` как список запретов, стоп-лист.
2. Новый продукт `chat` («Переписка») — 300 ₽, бесплатное мини 1 раз; безлимит в VIP и в ЛЮБОВЬ+ (как «Любовь»).

## Product `chat`

- Ввод: текст / пересланные сообщения / скрины чата → одно статус-сообщение (без спама) → «Готово».
- Без шага «кто ты в переписке» — модель сама читает «Переслано от…» и подписи на скринах.
- Промпты: `prompts/leia/full_chat.md`, `mini_chat.md`.
- Entitlements: `LOVE_PLUS_PRODUCTS = (love, chat)`; VIP уже покрывает всё.

## Риски и побочные эффекты

- Массовая пересылка больше не шлёт N уведомлений — только edit одного статуса.
- Скрины идут в KIE как `image_url` (нужен рабочий upload); лимит 12 фото.
- Старые payment payload с `chat_role=` всё ещё парсятся (роль игнорируется).
