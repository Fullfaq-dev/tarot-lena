# Сайт Леи: квиз вместо лендинга

Статус: **[Approved]** — реализация по плану.

## Summary

Статический лендинг `site/index.html` заменяется мобильным квиз-сервисом из ТЗ. Человек выбирает ситуацию, отвечает на вопросы, видит бесплатный кусок, платит на сайте. Telegram-бот — канал удержания после оплаты, не шаг воронки. Регистрации нет. Юридическая страница `site/legal.html` остаётся.

## Воронка

12 экранов как в `leya-prototype.html`. Ветка таро: ритуал → дуга карт. Ветка даты/пары: без ритуала, поля дат. Карта дня бесплатна целиком и ведёт к подписке, не к пейволу.

Каталог сайта отделён от каталога бота. SKU: `web_love_spread`, `web_marry`, `web_return`, `web_other` (590 ₽, 3 карты), `web_matrix`, `web_compat`, `web_money_channel`, `web_forecast`, `web_job`, `web_daily` (0 ₽), `web_unlimited_month` (590 ₽). Безлимит сайта не открывает VIP бота.

## API и данные

- `GET /api/web/cards` — публичный конфиг без промптов.
- `POST /api/web/sessions` — гость, utm, client_id.
- `POST /api/web/readings` — расчёт, мини-сборка, токен на год.
- `GET /api/web/readings/{token}` — мини всегда; `paid_text` только после оплаты.
- `POST /api/web/readings/{token}/checkout` — Robokassa или demo.
- `POST /api/web/readings/{token}/contact` — почта/tg и две пустые галочки.
- `POST /api/web/events` — цели Метрики (дубль на бэкенд).

Таблицы: `web_sessions`, `web_readings`, `web_card_overrides`, `web_matrix_cache`.

Мини на экране 6 — генерация через OpenAI (`verdict` / `body` / `hook`, один JSON). Карта дня остаётся из библиотеки. Платный текст не отдаётся клиенту до ResultURL. Один пакет оплаты; в подарок 3 уточняющих вопроса к разбору, строка про алгоритм по ветке, зачёркнутая цена `price_rub + 3 × question_price_rub` только при `show_strike_price`. Докупка 1/5 вопросов. Лимит мини: 5 с устройства и 20 с IP в сутки. Выход в Telegram с экранов мини/пейвола; бот шлёт мини и один бесплатный вопрос.

Диплинк: `t.me/<bot>?start=web_<token>`.

После оплаты человек всегда попадает на `/r/{token}` (полный разбор с чатом). SuccessURL мерчанта `/lk` перехватывается: логин не нужен. Касса открывается в попапе/iframe, страница мини не закрывается.

## Риски и побочные эффекты

- Два прайса сайт/бот: разные SKU, в выдаче пометка «разбор с сайта».
- `Payment.user_id` остаётся, для гостя создаётся пользователь с отрицательным `telegram_id`; в Telegram ему не пишем.
- Рекуррент 590 ₽ в MVP — те же 30 дней, что подписки бота, с явной галочкой; автопродление Robokassa не включаем без отдельной настройки мерчанта.
- SMTP может отсутствовать: тогда письмо не уходит, ссылка живёт на сайте.
- Чужие картинки Tilda не используем — только `/static/tarot_cards`.
- Юр. риск «живой таролог»: на экране бота явно ИИ.
